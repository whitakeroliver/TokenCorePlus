## Installation

1. Clone the repository: `git clone https://github.com/harutosati/TokenCorePlus.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

TokenCorePlus is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
